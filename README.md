# Jumia Product Data Analysis

## Project Overview
An Excel-based analysis of Jumia product listings to understand pricing, discounts, customer reviews, and product ratings.

## Dataset
The dataset contains 109 unique product listings with:
- Product names
- Current and old prices
- Discounts
- Reviews
- Ratings

## Tools Used
- Microsoft Excel
- Excel formulas
- Data cleaning
- Pivot tables
- Charts and dashboard

## Data Cleaning
- Removed duplicate products
- Cleaned currency symbols and commas
- Converted price ranges into midpoint values
- Cleaned review counts and ratings
- Kept missing values blank

## Analysis
The project analyses:
- Price categories
- Discount categories
- Rating categories
- Top products by reviews
- Top products by rating
- Average price, discount, reviews, and rating

## Dashboard
The dashboard presents key KPIs and visualisations for quick understanding of the product data.
